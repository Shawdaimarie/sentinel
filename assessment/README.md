## Scoring

Scores use the custom rubric in the baseline. It is still a draft awaiting
owner confirmation. The official OpenSSF Scorecard result is reported
separately and is never merged into the custom score. A point is awarded only
with dated, linked evidence. Steps 16–19 need sustained observation, so
configuration changes alone earn no credit for them.
