## License reality

A license can define permitted and prohibited use. It cannot physically prevent
someone from copying a public file. Protection comes from a combination of clear
license terms, attribution records, commit history, private handling of sensitive
assets, contract terms for paid work, and, when needed, legal advice from a
qualified professional.

## Public-proof standard

A public artifact is safest to show when it contains:

1. visible authorship and attribution;
2. reproducible code or documented methodology;
3. tests, CI, reports, or examples;
4. clear limitations;
5. no secrets or sensitive personal data;
6. no confidential client material; and
7. a separation between demonstration code and paid implementation details.

## Commercial-use note

For paid work, the public repository should function as evidence of skill, not
as the full commercial delivery package. The commercial package can include
private scoping, client-specific integrations, deployment support, service-level
expectations, documentation, training, monitoring, and maintenance terms.
