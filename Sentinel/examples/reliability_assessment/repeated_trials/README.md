# Repeated synthetic trials

Three hand-authored cases each have three successful synthetic observations.
No model or business system was executed. The correct reliability outcome is
**inconclusive**, not pass.

Follow the [command and interpretation guide](../../../docs/REPEATED_TRIAL_RELIABILITY.md).
The checked-in [expected report](expected-report.md) shows missing statistical
prerequisites while preserving the successful conformance observations.

The manifest fingerprints the exact case/run files. If either file changes,
its digest must be deliberately updated and the assessment rerun. The source
commit identifies the blueprint baseline; the fixture versions identify these
synthetic artifacts. Neither proves operational reliability.
